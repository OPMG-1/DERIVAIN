# DERIVATIVE RAIN — 미분 산성비

HTML, CSS, JavaScript로 만든 미분 타자 게임입니다.

## 플레이
`index.html`을 브라우저에서 열거나 GitHub Pages로 배포하세요.

## GitHub Pages 배포
1. GitHub에서 새 공개 저장소를 만듭니다.
2. 이 폴더의 `index.html`과 `README.md`를 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages**에서 **Deploy from a branch**를 선택합니다.
4. 브랜치를 `main`, 폴더를 `/ (root)`로 선택하고 저장합니다.
5. 배포가 완료되면 Pages에 표시되는 주소로 접속합니다.
